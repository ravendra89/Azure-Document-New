Periodic assessment: Enable this setting to automatically check for updates every 24 hours.

Hotpatch: Hotpatch allows you to install security updates on your Windows Server Azure Edition VMs and supported Arc-enabled machines with fewer reboots.

Patch orchestration: This setting allows you to control how patches are applied to your virtual machine.

I am not going to use this feature because when we enable Automatic Guest Patching on our Azure VMs, the patching of Security and Critical updates is handled entirely by Azure. We do not have control over the timing, nor can we choose which classifications or specific updates to install.
Everything is managed by Azure.

However, by using Azure Update Manager, we have full control over OS patching.
